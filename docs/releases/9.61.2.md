Linux と macOS 向けに、NNUE エディションのネイティブ版 `explain` を追加しました。従来の WASM / Windows 配布も同じリリースに含みます。

- Linux amd64 / arm64、macOS Intel / Apple Silicon の各環境に、KP256、HalfKP128、HalfKP256、HalfKP768、HalfKA1024 の5種類、合計20アーカイブを用意します。名前は `yaneuraou-<os>-<arch>-<network>-v9.61.2-explain.tar.gz` です。Linux amd64 と macOS Intel は SSE4.2 対応CPUが必要です。
- 全ネイティブ版を `HCE_EXPLAIN=ON` で作成します。`hce-progress.bin` と `hce-explain.bin` は同じリリースから別途取得してください。モデルは v9.61.1 と同一で、アーカイブには同梱しません。
- `usi`、モデルの `setoption`、`position startpos`、`explain moves 7g7f 3c3d 8h2b+ 3a2b` の順で、各局面の五項目を取得できます。この操作には NNUE の `nn.bin`、`isready`、`go` は不要です。探索には選択したエディションに合う NNUE が別途必要です。
- explain 対応ビルドでは、NNUE 未読込時の `position` が未初期化の評価関数にアクセスしないよう修正しました。NNUE 読込後の評価・探索は変更しません。
- 公開前に、4環境と5エディションの全20組でビルドと実行を確認します。検証は NNUE 無しで根の局面、通常の着手、捕獲、成り、`parts` の `material` / `tempo` / `speed` / `king` / `activity` を確認するもので、NNUE 探索や Windows 実行の検証ではありません。

詳細な対応環境と操作例は [README のネイティブ版 explain](https://github.com/shielune/YaneuraOu/blob/v9.61.2/README.md#ネイティブ版-explain) を参照してください。
