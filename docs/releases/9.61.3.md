NAGISA_V4 用の SFNN HalfKA_hm2 2304x2-15-64 (HalfKA2304) を、ほかの NNUE エディションと同じ形で配布に加えました。

- WASM の `pthread-halfka2304` (ブラウザ) と `node-halfka2304` (Node.js) を、通常版と `-explain` 版の両方で用意します。名前は `yaneuraou-wasm-pthread-halfka2304-v9.61.3.tar.gz` と `yaneuraou-wasm-pthread-halfka2304-v9.61.3-explain.tar.gz` です。初期メモリは評価関数が大きいため 512 MB です。
- Windows 版とネイティブ版 `explain` (Linux amd64 / arm64、macOS Intel / Apple Silicon) にも HalfKA2304 を加えます。
- HalfKA2304 は v9.60.1 に後から追加したものの、v9.60.2 以降のリリースには入っていませんでした。v9.61.x の `explain` を含む変更は、このリリースで HalfKA2304 にも入ります。
- 評価関数 (`nn.bin` と `progress.bin`) は同梱しません。NAGISA_V4 の配布物から取得してください。`LS_BUCKET_MODE` の既定は `progress8ek` です。
- 公開前に、WASM の HalfKA2304 4 パッケージ (pthread / node × 通常 / explain) のビルドを確認しました。HalfKA2304 での実行、NNUE 探索、`explain` の出力は検証していません。ほかのエディションのエンジンは v9.61.2 と同じソースです。
