つようら王11 mini / micro 用の `ka4096` / `ka2048` WASM パッケージを、公式と同じ構造 (`SFNN_ka2_4096_8_64_progress8x` / `SFNN_ka2_2048_8_64_progress8x`) で作り直しました。**9.61.7 の `ka4096` / `ka2048` は公式の `nn.bin` を正しく読めず評価値が壊れるため、この版に置き換えてください。**

- 9.61.7 の `ka4096` / `ka2048` は shortcut 項のある別構造 (`*_7_64_progress8x`) でビルドされていました。H1 が 8 の倍数のときは shortcut 項を持たない規則を生成器に入れ、公式と同じ `8_64` の形状に直しました。
- 新規パッケージのスレッドごとのスタックを 16 MiB から 8 MiB に下げました (実測の最小値は mini 約 4.5 MiB、micro 約 2.5 MiB)。
- `ka4096` / `ka2048` のネイティブビルドを追加しました。
- `ka4096` / `ka2048` 以外のパッケージは、名前も構造も 9.61.7 から変更していません。
- 評価関数 (`nn.bin` と `progress.bin`) と `FV_SCALE=24` の指定は 9.61.7 と同じです。
