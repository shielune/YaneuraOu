# Mobility 評価関数 — 特徴量レイアウト

## 概要

駒種 × 方向 × 距離 の線形評価。**114 次元**（盤上 107 + 持ち駒 7）。

バイナリファイル `weights.bin` の形式：
```
[4 bytes]   magic: "MOBI"
[4 bytes]   uint32 LE: 次元数 (114)
[456 bytes] float32 LE × 114
```

---

## 盤上駒 [0, 107) — 107 次元

左右対称（df を absolute 化）・金型エイリアス適用済み。

| index | 駒種 | 次元数 | 内容 |
|-------|------|--------|------|
| 0 | 歩 | 1 | 前1マス |
| 1–8 | 香 | 8 | 前1〜8マス |
| 9 | 桂 | 1 | 桂跳び1パターン |
| 10–12 | 銀 | 3 | 前 / 前斜 / 後斜 |
| 13–16 | 金型（金・成歩・成香・成桂・成銀 共有） | 4 | 前 / 前斜 / 横 / 後 |
| 17–21 | 玉 | 5 | 8方向 → 左右対称で5 |
| 22–37 | 角 | 16 | 斜め × 8距離 |
| 38–61 | 飛 | 24 | 前後横 × 8距離 |
| 62–80 | 馬 | 19 | 角16 + 直交隣接3 |
| 81–106 | 龍 | 26 | 飛24 + 斜め隣接2 |

1+8+1+3+4+5+16+24+19+26 = **107**

## 持ち駒 [107, 114) — 7 次元

打てる全合法升からの総利きマス数 × 枚数 を1次元に集計。
馬・龍は持ち駒として存在しないため対象外。

| index | 駒種 |
|-------|------|
| 107 | 歩 |
| 108 | 香 |
| 109 | 桂 |
| 110 | 銀 |
| 111 | 金 |
| 112 | 角 |
| 113 | 飛 |

---

## 設計メモ

- 持ち駒の特徴量は「方向×距離」で展開すると学習が全次元同じ係数に収束するため、v2 から1次元に統合
- 旧設計（v1）は 164 次元（盤上 107 + 持ち駒 57）
