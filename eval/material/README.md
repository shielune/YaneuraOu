# Material 評価関数 — 特徴量レイアウト

## 概要

駒種ごとの駒価値を学習した線形評価。**17 次元**（盤上 10 + 持ち駒 7）。
オリジナルの MaterialLv1 との違い：**盤上と持ち駒で駒価値を別々に学習**している。

バイナリファイル `weights.bin` の形式：
```
[4 bytes]  magic: "MATW"
[4 bytes]  uint32 LE: 次元数 (17)
[68 bytes] float32 LE × 17
```

## 設計メモ

- 金型成駒（成歩・成香・成桂・成銀）は盤上での動きが金と同じなのでまとめて1次元
- 馬・龍は盤上のみ（持ち駒として存在しない）
- 持ち駒を盤上と別次元で学習することで「手持ちの駒の価値 > 盤上の同駒」を表現可能
