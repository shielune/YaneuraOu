# Changelog

## 9.60.0

### Added

- WebAssembly pthread and Node.js variants for NAGISA V3.1.
- NAGISA V3.1 accepts `nn.bin`, `progress.bin`, and `eval_options.txt` as external evaluation files.

### Changed

- WebAssembly releases link to external evaluation assets instead of bundling them.
- The V9.60 engine model is the base for WebAssembly builds.
